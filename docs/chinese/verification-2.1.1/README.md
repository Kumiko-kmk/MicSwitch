# 2.1.1 全局输入修复

- 将控制存活检测和保护进程心跳从 WPF 悬浮窗刷新移至独立定时器，不再依赖鼠标位置或窗口绘制。
- 热键短暂延迟只触发静音，不再永久设置会话锁定状态。
- 增加 GetAsyncKeyState 按键状态后备检查；保留 hook 以支持绑定与拦截。对被自身 hook 拦截的按键避免错误使用异步状态。

验证：无边框全屏置顶窗口覆盖悬浮窗，光标在其他位置，每次注入前确认前台窗口句柄，100轮全部通过。开麦中位31.00ms、最大33.30ms；松键中位16.12ms、最大17.65ms。界面线程停顿3.5秒仍可控制；移除hook后的后备开麦/松键测试通过；原有键盘、组合键、侧键、锁定和设备离线回归通过；异常退出保护通过。

按用户要求没有启动具体游戏。这是无边框全屏窗口与全局输入回归，不能等同于所有游戏/反作弊的兼容性认证。管理员权限不同、安全桌面、其他底层拦截仍有系统边界。较早版本的普通前台测试并未覆盖本次发现的界面停顿问题。
