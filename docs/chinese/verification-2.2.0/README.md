# 2.2.0 验证

用户反馈 2.1.1 在实际使用中仍依赖鼠标停留悬浮窗；上一版模拟测试未覆盖用户的真实输入环境，不能据此宣称所有游戏已兼容。

本版新增独立输入线程上的隐藏窗口，使用 Raw Input / RIDEV_INPUTSINK 接收后台鼠标按钮事件；保留低级钩子和按键状态后备，统一按下状态去重。默认关闭按键拦截，迁移旧设置。新增持久化的按住说话、按键切换两种模式，重复按下不会反复切换。

## 验证方式与结果

- `regression.txt`：界面停顿 3.5 秒、鼠标中键及双侧键、键盘组合键、绑定、锁定、休眠状态、设备离线、设置保存；新增切换模式、重复输入、启用拦截时切换、仅原始输入时开关等检查，全部通过。
- `fullscreen-raw-hold.txt`、`fullscreen-raw-toggle.txt`：禁用低级钩子和按键状态轮询，仅原始输入接收鼠标事件，两种模式各 100 次开关。
- `fullscreen-normal-hold.txt`、`fullscreen-normal-toggle.txt`：正常多路监听，两种模式各 100 次开关，验证没有双重切换。
- 全屏测试由独立进程创建无边框全屏窗口覆盖悬浮窗，鼠标位于 (400,400)，每次输入前核实前台窗口，直接通过 CoreAudio 读取所有输入端点静音状态。强制退出后检查独立静音保护。
- 切换模式的计时包含测试程序模拟点击时主动等待的 20 ms，不应直接与按住模式延迟比较。

最初两轮因前台焦点获取失败判为无效；测试补充获取前台焦点的步骤后，仍逐次核实焦点，再完成上述回归。

输入由 Windows 注入 API 生成，原始输入路径已单独验证，但未启动用户游戏，未实测其物理鼠标驱动、反作弊或安全桌面。无法保证所有外部输入拦截环境都可用。没有将悬浮窗图标变化当作系统静音成功的依据。
